# 知余

本地记账应用。账单、账户、预算、日历、资产和理财放在同一套结构里，数据默认只存在本机。

- 包名：`com.shifeng.zhiyu`
- 当前版本：`1.0.0`（versionCode 21）

## 下载

安装包挂在 GitHub Release。这个仓库只用来发布更新，不托管源码。

- 最新版：<https://github.com/ShiFeng546/zhi-yu/releases/latest>
- 1.0.0：<https://github.com/ShiFeng546/zhi-yu/releases/download/v1.0.0/zhiyu-1.0.0-release.apk>
